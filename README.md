# Formula-Steering-Wheel-basen-on-Raspi-PI-PICO-W
Procedimiento y descripcion paso a paso para crear un Aro estilo fórmula, impreso en 3D, con 4 levas digitales, 8 botones, 3 encoders rotativos, 2 swtiches de encoders y un encoder con funcion multinivel de 5 switches virtuales de seleccion de estado ciclico.

Su primera concepción se utiliza con la base PXN V10. Direct Drive Force Feedback.

# Planes de mejoras a futuro:
**Mejoras de Grip:**
  * Agrandar la circunferencia de los grips para mayor ergonomía.
  * Implementación de un material elastómero para mejorar el grip y sujeción

**Cambio en el Hardware**
  * Utilización de placas controladoras con mayor compatibilidad de uso.
  * Implementación de display, dashboards, timers.

**Compatibilidad**
  * Creación de Quick Release genéricos para la compatibilidad con más bases.
  * Posibilidad de software para personalizar aro.
